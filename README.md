### Installation

Paste this inside of your console (you need to have [GIT](https://git-scm.com/) and
[Maven](https://maven.apache.org/) installed).

```bash
git clone https://github.com/s2004Dev/BAT-Starter.git
cd ./BAT-Starter
mvn clean install
```

After this you should be able to open and run the project inside your chosen IDE.
